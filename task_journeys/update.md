# User Journey for Updating a Task

Start: Existing task/s with components.

Finish: Task/s Updated with a different component/s.

## Steps

1. Open Program
2. Choose Task CRUD Menu
3. Choose Update Option
4. Choose Task to Modify via:
    1. Task Number/ID
    2. Task Name
5. Choose Component to Modify from:
    1. Title
    2. Description
    3. Steps
6. Type Out New Component Content
7. Task Updated in Database
8. Return to Component Option Menu
9. Return to Task Option Menu
10. Return to CRUD Menu
11. Return to Main Menu
12. Finished
