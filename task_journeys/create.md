# User Journey for Creating a Task

Start - No task.

Finish - Task Created in Database.

## Steps

1. Open Program
2. Choose Task CRUD Menu
3. Choose Create Option
4. Fill in Title
5. Fill in Descriptions
6. Fill in Steps
7. Complete Creation
8. New Task in Database
