# User Journey for Deleting a Task

Start - Task in Database

Finish - Task No Longer in Database

## Steps

1. Open Program
2. Choose Task CRUD Menu
3. Choose Delete Option
4. Choose Task to Delete via:
    1. Task Number/ID
    2. Task Name
5. Confirm Deletion
6. Task Removed from Database
7. Return to Task Option Menu
8. Return to CRUD Menu
9. Return to Main Menu
10. Finished
